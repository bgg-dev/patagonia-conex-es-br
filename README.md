# Patagonia Conexões BR

Crea una landing page en React y Tailwind CSS en portugués llamada "Patagonia_br" para turistas de Brasil que viajan a la Patagonia Argentina desde São Paulo (GRU) y Río de Janeiro (GIG).

### Diseño y Estructura

- **Estilo:** Tarjetas limpias blancas con bordes muy redondeados (`rounded-[2.5rem]`), sombras suaves y contenido centrado (sin fotos de fondo).

- **Transporte:** Contenedores cuadrados de 80x80px con borde negro de 2px (`border-2 border-slate-900 rounded-2xl`) e ícono outline de avión o micro.

- **Secciones:**

  1. **Hero:** Título *"Descubra a Patagônia Argentina: Conexões de São Paulo e Rio de Janeiro"* y subtítulo de planificación por presupuesto.

  2. **Rutas Aéreas:** Conexiones desde GRU y GIG hacia la Patagonia (directas estacionales o vía Buenos Aires con Aerolíneas Argentinas, LATAM, GOL).

  3. **Destinos Patagónicos:** Tarjetas para Bariloche (BRC), Ushuaia (USH), El Calafate (FTE) y Puerto Madryn (PMY) con datos de estadía estimada.

  4. **Monetización:** Botones de CTA optimizados para afiliados de Booking.com por cada destino.
